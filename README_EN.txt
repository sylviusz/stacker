======================================================
STACKER- by Sylwiusz Starczewski, Przemysław Jasiński
======================================================

A simple, fast-paced arcade game written in C for ATmega328p (arduino nano clone).
The main goal is to build a tower that is 32 blocks high.

The higher you get, the faster the game becomes, making it challenging to reach
the top.

======================================================
FEATURES
======================================================
*32 levels of increasing speed and difficulty
*Win and fail mechanics with audio-visual feedback
*Written in C without arduino framework

======================================================
HARDWARE
======================================================
Components bought straight from trusted friends in China :)
*Microcontroller: Arduino nano clone
*Display: MAX 7219 8x32 LED matrix
*Input: 1x simple button
*Audio 1x Buzzer for sound effects

PROJECT FILES
